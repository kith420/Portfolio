# Nathan Poernama

My portfolio: experience, competitions, projects, and the tools I build with.

Built with Next.js, TypeScript, and CSS Modules.

## Run locally

```sh
npm install
npm run dev
```

Then open [localhost:3000](http://localhost:3000).

## Editing content

All copy lives in `src/content/`, one file per section. Images go in `public/images/`.
